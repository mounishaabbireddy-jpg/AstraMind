# AstraMind MVP

AstraMind is an AI assistant built during a hackathon. This repository contains the Hackathon Standard Operating Procedure (SOP) and a basic Flask Minimum Viable Product (MVP) app.

## Project Structure
- `app.py`: The main Flask application (contains simple UI and `/api/chat` backend route).
- `SOP.md`: The hackathon strategy and timeline document.

## How to run locally
1. Install Python.
2. Install Flask: `pip install flask`
3. Run the app: `python app.py`
4. Visit `http://127.0.0.1:5000` in your web browser.
